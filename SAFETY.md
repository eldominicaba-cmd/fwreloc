# fwreloc — Safety & Liability Contract

## Purpose
This project is a **learning and legitimate compatibility/migration tool**.
It does *not* reverse engineer, cheat, or undermine DRM, anti-cheat, online
services, or any software the user is not authorised to own.

## Scope of a legitimate engagement
* Firmware dumps of the user's **own hardware** (retro handhelds, debug
  boards, singleplayer single-chip devices — anti-cheat-free).
* Local, offline analysis. Nothing is uploaded to a server.
* Comparison and patch emission **only**. No data extraction, no
  exfiltration, no monetisation of the user's private firmware.

## Red lines (do not cross, regardless of payment)
1. No DRM circumvention.
2. No anti-cheat bypass / online-progression manipulation.
3. No multiplayer cheating or account fraud.
4. No redistribution of cracked/pirated installs, ROMs, or firmware.
5. No access to accounts or personal data beyond the firmware file itself.
6. No storage of personal/PHI data.

## Liability / indemnity
* User indemnifies fwreloc against claims arising from misuse.
* fwreloc takes no responsibility for any loss of service, brick, or legal
  issue caused by using this tool on a device the user does not own.
* Where in doubt, the user **writes a test on an owned, detached device**
  and only proceeds with a **signed, written licence** from the device owner.

## Confidentiality
Any user-supplied firmware is treated as confidential; removed on request or
at the end of the engagement.
