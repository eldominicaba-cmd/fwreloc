## Tagline
Two firmware dumps. One plain-English report on what changed.

## Description
You have two firmware builds and you need to know what changed between them.
Not a function table — an actual read on the change:

- Executive summary (≤ 150 words)
- Diff summary (functions added / removed / changed)
- Changed functions table with a one-line note on each
- Compatibility / readiness note (does this load the same game, save file,
  or boot path you care about?)
- Scope boundaries, clearly stated

The customer supplies the two firmware dumps. I do the analysis.
